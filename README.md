# Collective learning

Physics-first study of spontaneous differentiation in populations of coupled learning units, starting from Arola-Fernández and Lacasa, *Effective theory of collective deep learning*, Phys. Rev. Research **6**, L042040 (2024).

The repository is split between compute and local presentation.

## Minerva

Minerva only runs simulations and pushes canonical result files.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-compute.txt

./experiment.sh
```

`experiment.sh` is resumable. It computes the effective-theory baseline once, then the MNIST baseline seed by seed. Each completed result is committed and pushed immediately. Existing result files are skipped; use `FORCE=1 ./experiment.sh` to recompute them.

Tracked outputs are:

```text
results/theory_baseline.npz
results/mnist_seed0.json
...
results/mnist_seed9.json
```

## Local Mac

The local machine only pulls results, renders figures, and compiles LaTeX.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-plot.txt

./build.sh
```

`build.sh` runs `git pull --ff-only`, regenerates any figures whose result files are available, and compiles `draft/main.tex` with `latexmk`.

The current baseline figures are generated by

```text
draft/figures/fig1.py   # effective theory
draft/figures/fig2.py   # MNIST baseline
```

Generated PDFs are not committed.

## Code

`collective.py` contains the reusable coupled-SGD step,

```text
theta_i <- theta_i - eta grad L_i
           + eta sigma/N sum_j q_ij (theta_j - theta_i)
```

and already accepts optional per-sample weights. With no sample weights it reproduces the Arola-Lacasa baseline. The adaptive-genotype model will enter through those weights while leaving the coupling machinery unchanged.

`reproduce_theory.py` computes the released effective Ginzburg-Landau baseline. `reproduce_mnist.py` computes the MNIST neural-network baseline.

The mathematical formulation of the new model is in `draft/main.tex`.
