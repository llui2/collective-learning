# Collective learning

Physics-first study of spontaneous differentiation in populations of coupled learning units.

The starting point is the effective theory of collective deep learning of Arola-Fernández and Lacasa (Phys. Rev. Research 6, L042040), where local learning competes with coupling between learners.

The central question here is:

> Can functional heterogeneity and division of labor emerge spontaneously among coupled learning units exposed to the same environment?

The previous mixture-of-experts routing experiment has been removed. The next model will be built from this question rather than from a specific neural architecture.
