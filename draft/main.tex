\section{Learning changes the interaction network}

In modern mixture-of-experts (MoE) transformers, a router chooses which
feed-forward experts receive each token \cite{fedus2022,mixtral2024,deepseek2024}.
Expert learning then changes the functions available to the router.
This creates a feedback between allocation and representation learning,
different from parameter diffusion among learners \cite{arola2024}.
The coupled dynamics of soft routers and experts are themselves an
active subject of theory \cite{liao2026}.

The immediate question is whether an initially symmetric router--expert
system is unstable to \emph{complementary specialization}, while remaining
stable against \emph{load collapse}. We start from an exactly tractable
soft-routing reduction. It is not a transformer and does not implement
sparse top-$k$ selection; these are subsequent tests.

\section{Two experts and two token populations}

A token has a population label $c\in\{-1,1\}$, equally likely, and a
scalar feature $z$ with $\langle z^2\rangle=1$. Its regression target
is $y=cz$. Expert $i$ predicts $f_i(z)=w_i z$.
The router sees $c$ and assigns expert 1 probability
\begin{equation}
p(c)=\frac{1}{1+\exp[-(b+cq)/T]},
\qquad p_2(c)=1-p(c).
\label{eq:routing}
\end{equation}
Here $q$ discriminates token populations, $b$ biases total expert load,
and $T>0$ is the routing temperature. The soft-MoE prediction is
$\hat y=[p(c)w_1+(1-p(c))w_2]z$.

We train both experts and the router on
\begin{equation}
E=\frac12\left\langle(\hat y-y)^2\right\rangle
+\frac{\kappa_e}{2}(w_1^2+w_2^2)
+\frac{\kappa_r}{2}(q^2+b^2)
+\frac{\lambda}{2}\left(\bar p-\frac12\right)^2,
\quad
\bar p=\frac12\sum_{c=\pm1}p(c).
\label{eq:loss}
\end{equation}
The last term penalizes aggregate load imbalance, but not conditional
specialization. Expert and router parameters follow gradient descent,
with independent learning rates:
\begin{equation}
\dot w_i=-\eta_e\partial_{w_i}E,\qquad
\dot q=-\eta_r\partial_qE,\qquad
\dot b=-\eta_r\partial_bE.
\label{eq:dynamics}
\end{equation}
Thus routing is learned, not an allocation imposed on the experts.

Introduce the mean expert $m=(w_1+w_2)/2$ and contrast
$d=(w_1-w_2)/2$. Since $2p(c)-1=\tanh[(b+cq)/(2T)]$,
the expected data loss is exactly
\begin{equation}
E_{\rm data}
=\frac14\sum_{c=\pm1}
\left[m+d\tanh\left(\frac{b+cq}{2T}\right)-c\right]^2.
\label{eq:reduced}
\end{equation}
The two observable routing modes are
\begin{equation}
S=p(1)-p(-1),\qquad C=p(1)+p(-1)-1.
\label{eq:orders}
\end{equation}
Complementary routing has $S\ne0$, $C=0$; collapse of token
allocation toward one expert has $S=0$, $C\ne0$. A functional
specialization also needs nonzero $d$ aligned with $S$.

\section{Linear stability}

The fully symmetric state $m=d=q=b=0$ is stationary.
To quadratic order, the energy reads
\begin{equation}
E=\frac12+\left(\frac12+\kappa_e\right)m^2
+\kappa_e d^2+\frac{\kappa_r}{2}(q^2+b^2)
-\frac{qd}{2T}+\frac{\lambda b^2}{32T^2}
+O(\|(m,d,q,b)\|^3).
\label{eq:expansion}
\end{equation}
Because $m,d$ are linear combinations of two independent expert
weights, their gradient-flow mobilities are $\eta_e/2$, not $\eta_e$.
The two coupled perturbations satisfy
\begin{equation}
\frac{d}{dt}
\begin{bmatrix}d\\q\end{bmatrix}
=
\begin{bmatrix}
-\eta_e\kappa_e&\eta_e/(4T)\\
\eta_r/(2T)&-\eta_r\kappa_r
\end{bmatrix}
\begin{bmatrix}d\\q\end{bmatrix}.
\label{eq:jacobian}
\end{equation}
Their larger eigenvalue is
\begin{equation}
\omega_+=-\frac{\eta_e\kappa_e+\eta_r\kappa_r}{2}
+\frac12\sqrt{(\eta_e\kappa_e-\eta_r\kappa_r)^2
+\frac{\eta_e\eta_r}{2T^2}}.
\label{eq:growth}
\end{equation}
For positive regularization, the symmetric state is unstable to
specialization precisely when
\begin{equation}
T<T_c=\frac{1}{\sqrt{8\kappa_e\kappa_r}}.
\label{eq:critical}
\end{equation}
In contrast, the load-bias mode obeys
\begin{equation}
\dot b=-\eta_r\left(\kappa_r+
\frac{\lambda}{16T^2}\right)b+O(\|(m,d,q,b)\|^2).
\label{eq:collapse}
\end{equation}
Load balancing therefore damps collapse without suppressing the
linear specialization instability. The symmetric mean-expert
perturbation $m$ also decays, at rate
$\eta_e(1/2+\kappa_e)$.

\section{Scope and next tests}

This reduction intentionally gives each expert insufficient capacity to
represent both opposing token populations: each computes only one
scalar slope. The instability demonstrates a minimal mechanism, not
an unexplained discovery of new transformer behavior. The nonlinear
long-time state and finite-size noise may also depend on the
regularization and initialization.

As a first microscopic test, the accompanying code also trains
two ReLU feed-forward experts on actual token samples. In this model
each expert receives both the population label and the continuous
feature, so either expert has sufficient representational capacity
to learn both token populations. The learned router can use soft
top-two mixing or selected-gate top-one routing with a per-expert
token limit. We measure conditional routing, actual dispatched loads,
overflow and class-conditional expert errors. Thus changes in routing
are not automatically interpreted as functional specialization.

This token-level model is still an isolated MoE feed-forward layer:
the token representations are fixed, and its reference implementation
masks expert outputs rather than implementing efficient sparse dispatch.
The next step is to test which features of
Eqs.~\eqref{eq:jacobian}--\eqref{eq:collapse} survive with learned
representations inside an actual transformer.
